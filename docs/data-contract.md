# 纠删码资料约定

所有原始块是字节向量，乘加分别在GF256及异或上完成。primitive polynomial=0x11d。V的第i行第j列为(i+1)^j，i从0到k+m-1，j从0到k-1；G=V*(V前k行)^-1，固定行号不重排，k+m<=255。数据块先按stripe再按数据行顺序映射原文，末尾零填充，填充不计入original_length。只做已校验分片的擦除恢复，不接收“多数看起来一致”的坏片纠错。

available记录本次模拟来源能否返回，不改变分片内容身份。未写generation的分片继承父清单代；显式不同代拒绝。每行可有多个镜像，但只有同内容身份的通过副本可加入该行方程。缓存键包括generation/stripe/row及sha。重复行场景是合法请求材料但无法形成足够独立方程。

下载适配器由可信代码传入，来源返回原始字节或失败，不执行清单命令。budget按实际返回body字节记，坏副本也计；max_buffered_stripes限制恢复活跃条带。初始工程只核对资产，不执行GF运算。
